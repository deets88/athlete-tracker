# Athlete Tracker

Athlete Tracker is a web app made for coaches and coordinators to keep all student athlete information in one place. You can upload your own CSV spreadsheets or view/edit data already on the site. Add, sort, filter, search, and edit athlete information—no tech skills needed!

## 🚀 Get Started

1. **Go to [athlete-tracker-ten.vercel.app](https://athlete-tracker-ten.vercel.app)**
2. **Sign in using your HKIS school email address.**
3. You’ll see sample data right away after signing in, or you can upload your own CSV spreadsheets at any time.

## 📂 Uploading Spreadsheets

- The app accepts spreadsheets in **CSV format**.
- You can upload **multiple files**—the app adjusts automatically to different formats.
- No need to worry about typos in column names or special headers.
- *Example:*

    ```
    Group, Varsity Girls Rugby,,,,,Student Last Name,Student First Name,Student Other Name,Gender,Student Email Address,Year/Grade,,,,,,,,,,,,,,
    HS - Season 1 - Girls Varsity Rugby Team 2025/26,,,,,El Asmar,Lea,,F,270134@hkis.edu.hk,11,,,,,,,,,,,,,,
    ...
    ```

## 🏆 Top Features

- **View and edit** athlete info directly from your web browser.
- **Sort, search, and filter** by any field (like name, team, grade, etc.).
- **Supports multiple teams and groups** in one place.
- **Works on any browser**, best on a computer.

## 🔒 Login & Privacy

- Only users with an HKIS school email can access the site.
- No exports—data stays within the app and is secure.

## 🏉 Example Data

- When you sign in, you’ll see real sample athlete data so you can start right away—no upload needed.
- You can delete or edit the sample entries, or upload your own team’s spreadsheets.
